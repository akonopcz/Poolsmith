# Poolsmith

Visual ZFS pool and vdev planner that runs in the browser. It plans layouts only and never
runs commands on a host.

Status: early development. `src/core/` covers the MVP: data model, validation, warnings,
capacity estimates, plan files and exports. The UI comes next. See [docs/spec.md](docs/spec.md)
for scope and design.
